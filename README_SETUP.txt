POLITICAL ATLAS V6 — FREE IPHONE / ANDROID / PC APP

Recommended: publish with GitHub Pages (free for public repositories).

1. Go to https://github.com and create a free account (if needed).
2. Click + → New repository. Name it political-atlas, set Public, click Create repository.
3. Choose "uploading an existing file" (or Add file → Upload files).
4. Upload the CONTENTS of this folder: index.html, manifest.webmanifest, sw.js, and the icons folder.
   GitHub web upload can preserve the icons folder by dragging the entire folder in, or upload its three PNGs into icons/ using the website.
5. Commit changes.
6. Go to Settings → Pages → Build and deployment → Deploy from a branch.
7. Choose branch main and folder /(root), click Save.
8. GitHub will publish a URL like https://YOUR-USERNAME.github.io/political-atlas/
   It may take several minutes before the URL works.

On iPhone: open your published URL in Safari → Share → Add to Home Screen → enable Open as Web App → Add.
On Android: open published URL in Chrome → menu → Install app or Add to Home screen.
On Windows: open index.html directly or visit your published site.

IMPORTANT:
- Do not upload the ZIP as the website; unzip it and upload the files inside.
- Install/offline cache requires HTTPS (GitHub Pages provides it) or localhost.
- Hosting a public GitHub Pages repository makes the app's source code publicly visible.
- This app does not send quiz answers to a server. They stay in your browser's local storage.
- Clearing your browser data or using another device loses local saves. Use the app's result code / JSON export to transfer them.
- Some features, including Web Share/install UI, depend on phone/browser version.
- The political matches and historical parallels are educational approximations.
